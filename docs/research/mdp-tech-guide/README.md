# Investigación de la guía tech de Mar del Plata

Material de base para la sección `/guia` de mardelplata.dev.ar.

- `RESEARCH.md` y `SITEMAP.md`: pasadas del 28 y 29 de septiembre de 2026.
- `GAPS.md`: estado de los huecos al 23 de noviembre de 2026.
- `PASADA-2026-11-23.md`: fuentes y correcciones de la pasada que publica la guía.
- `PEOPLE_CANDIDATES.md`: candidatos para una página de personas. No se publica hasta que cada una dé permiso. La página `/guia/gente` solo lista cuentas institucionales.

Este directorio es documentación. El contenido público está en `src/content/guia/`.
